# Third-Party Integrations

## 1. AWS Cognito
Purpose: user authentication.
Requirements:
- Configure user pool and app client.
- Define callback and logout URLs.
- Use authorization code flow with PKCE for browser-based sign-in where applicable.
- Validate tokens in FastAPI.
- Map Cognito `sub` to internal users.
- Keep client secrets and AWS credentials out of browser code.

## 2. AWS S3 and CloudFront
Purpose: store and deliver media.
Requirements:
- Private S3 bucket.
- CloudFront distribution with Origin Access Control.
- Upload through short-lived presigned URLs generated by backend when needed.
- Validate content type, size and file extension.
- Randomized object keys; do not trust user filenames.
- Configure cache-control and invalidation strategy.
- Restrict CORS to required origins.

## 3. OpenRouter
Purpose: AI recommendations and optional data enrichment.
Requirements:
- Server-side API calls only.
- Timeouts, rate limits and bounded retries.
- Model and prompt configurable through environment/config.
- Structured output validation.
- Usage and cost logging.
- Fallback to non-AI search.
- Do not send secrets or unnecessary personal data.

## 4. Tiun Business
Purpose: payments.
Before implementation, verify current official documentation for:
- API authentication
- Checkout/session creation
- One-time and recurring payments
- Webhook signatures
- Refunds and cancellations
- Subscription lifecycle events
- Test/sandbox environment
- Settlement and supported currencies

Do not guess endpoint URLs, payloads or signature schemes. Implement against verified provider documentation and create webhook contract tests.

## 5. Resend
Purpose: transactional email.
Use for verification-related messages if configured, submission updates, vendor notifications and product notifications. Keep templates versioned. Add retry handling and delivery event processing if required. Never send marketing email without appropriate consent.

## 6. PostHog
Purpose: product analytics.
Track events such as search performed, tool viewed, comparison created, save action, outbound click and submission completed. Avoid collecting sensitive fields or raw prompt content unless necessary and disclosed.

## 7. Integration policy
Wrap each provider in an adapter module. Domain logic should depend on internal interfaces, not provider SDK details. Use sandbox/test credentials in development and separate production credentials.
