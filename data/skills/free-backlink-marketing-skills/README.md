## ⚡ Quick Start: 2 Ways to Use

### 1. Claim Your Free Backlink in 5 Seconds (Zero-Install CLI)
Run this single command from your project root:

```bash
npx aitoolsfinder-submit
```
*(Or if cloned locally: `node scripts/submit.js --yes`)*

**What it does:**
1. Automatically reads your `package.json`, `README.md`, and git remote to detect your product name, tagline, and official URL.
2. Validates your payload and submits it to [AIToolsFinder.cloud](https://aitoolsfinder.cloud).
3. Claims your **permanent, verified dofollow backlink**.
4. Automatically injects the **Verified Trust Badge** into your `README.md`.

### 2. Install the 56+ Marketing Skill Suite into Your AI Agent
Give your AI coding assistant (Cursor, Antigravity, Claude Code, or any agent following the Skills specification) the capabilities of an entire 10-person growth team:


Now, simply tell your agent in chat:

Or:

## 💻 CLI Usage Details

The built-in CLI utility in `scripts/submit.js` (and `aitoolsfinder-submit`) can be run anytime:

```bash
# Interactive mode (prompts and auto-detects)
node scripts/submit.js

# Agent / Headless mode (accepts all defaults)
node scripts/submit.js --yes

# Specify email explicitly
node scripts/submit.js --yes --email=founder@yourdomain.com

# Dry-run mode (previews submission JSON without making HTTP request)
node scripts/submit.js --dry-run
```
